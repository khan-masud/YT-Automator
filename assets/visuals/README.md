# Happy Little Stars visual assets

Place approved visual files in this folder before running the video pipeline.

## Supported formats
- Images: `.jpg`, `.jpeg`, `.png`, `.webp`
- Videos: `.mp4`, `.mov`, `.m4v`

## Safe asset checklist
- Use original artwork or assets you have permission to use commercially.
- Use cheerful, age-appropriate preschool scenes: smiling stars, colorful skies, friendly animals, alphabet/number learning, toys, and bright daytime scenery.
- Avoid identifiable real children, personal information, copyrighted cartoon characters, watermarks, and assets downloaded without permission.
- Include enough different images/clips to avoid repetitive videos. The current loader cycles through files when more clips are needed.

The pipeline intentionally stops if no supported visuals are present. This README is documentation, not a visual asset, so add at least a few actual image/video files before running the workflow.
